# 🧠 Human Body Action Detection and Recognition using AI

An AI-powered web application that detects and recognizes human body actions from uploaded videos or live camera feeds using **Convolutional Neural Networks (CNN)** and **Extreme Learning Machine (ELM)**.

---

## 📌 Project Overview

Human Body Action Detection and Recognition is a machine learning project developed to automatically identify human activities from video sequences. The system analyzes body movements and predicts the performed action using a supervised learning approach.

The model was trained on the **UCF50 dataset**, which contains labeled videos of various human activities such as:

- 🏃 Running
- 🚶 Walking
- 🏊 Swimming
- 💃 Dancing
- ⚽ Playing Sports
- 🤸 Various Human Activities

The application allows users to upload videos or use a live camera feed to recognize actions in real time.

# 🧠 Machine Learning Pipeline

### Step 1 — Dataset Preparation

The model was trained using the **UCF50 Dataset**, which contains labeled videos representing different human activities.

---

### Step 2 — Feature Extraction (CNN)

The Convolutional Neural Network automatically learns important visual information from each video frame, including:

- Body posture
- Motion patterns
- Object shapes
- Edges
- Spatial features
- Human movement information

CNN eliminates the need for manual feature engineering by learning features directly from the dataset.

---

### Step 3 — Classification (ELM)

The extracted CNN features are passed to the **Extreme Learning Machine (ELM)**.

ELM performs:

- Human Action Classification
- Prediction
- Recognition

Its fast learning capability makes it suitable for real-time applications.
